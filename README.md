 Predictive Indian Stock Market Dashboard

An interactive **real-time stock market dashboard** designed to visualize Indian market trends, technical indicators, and sentiment analysis for smarter decision-making.

---

##  Features

* 📈 **Live Market Dashboard**

  * Tracks major indices like **NIFTY 50, SENSEX, BANK NIFTY**
  * Displays real-time price trends and movements

* 📊 **Technical Analysis**

  * Moving Averages (MA20, MA50)
  * RSI (Relative Strength Index)
  * Volume analysis

*  **AI-Powered Insights**

  * Generates market insights using AI models
  * Provides technical + fundamental summaries

*  **News Sentiment Analysis**

  * Aggregates financial news
  * Classifies sentiment: **Bullish / Bearish / Neutral**

*  **Market Breadth Analysis**

  * Visualizes advancing vs declining stocks

*  **Top Movers**

  * Displays top gainers and losers

*  **Interactive UI**

  * Toggle indicators (MA, RSI, Volume)
  * Timeframe selection (1D, 1W, 1M, 3M)

---

## 🛠️ Tech Stack

* **Frontend:** HTML, CSS, JavaScript
* **Visualization:** Chart.js
* **APIs:** REST APIs (AI insights, market simulation)
* **Concepts:** Technical Indicators (RSI, Moving Averages), Sentiment Analysis
